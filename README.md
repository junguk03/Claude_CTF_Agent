# Claude_CTF_Agent

웹 CTF·워게임 문제를 Claude Code와 함께 풀기 위한 작업 규칙, 분석 스킬, 문제 폴더 템플릿입니다.

> 허가된 대상(CTF·워게임 문제 서버, 직접 구축한 실습 환경)에만 사용합니다.

## 구성
| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | 작업 규칙: 플래그 우선, 요청 범위, 공격 허용 범위, 기록 방식, 오래 걸리는 작업, 성공 판정, 대회 모드 |
| `.claude/skills/web-ctf/SKILL.md` | 분석 순서: 구조 → 플래그 역추적 → 입력 지점 → 위험 함수 → 인증 → 해석 차이 → 후보 순위 → PoC → 블랙박스 → 추출 효율 |
| `_template/notes.md` | 문제별 기록: 현재 상태, 시험 표, 확인된 사실, 버린 가설, 진행 기록 |
| `_template/solve.py` | 풀이 스크립트 틀: 응답 전체를 `out/`에 저장, 플래그 자동 감지, Burp 프록시 연결, 요청 간격(`DELAY`) |
| `_template/writeup.md` | 라이트업 틀: 요약, 분석, 풀이, 플래그가 나온 응답, 사용 도구·AI 사용 범위 |
| `new.sh` | 문제 폴더 생성 |

## 사용법
```bash
./new.sh 문제이름 http://대상주소:포트 '플래그형식'
# 문제 파일은 문제이름/src/ 에 풀기
claude --permission-mode default
```

## 변경 기록
- v1: 규칙, 분석 스킬, 템플릿

- v3: 대회 모드(대회마다 채우는 빈칸: 규칙, 플래그 형식, AI 사용, 라이트업 마감), 라이트업 템플릿, solve.py 요청 간격, new.sh 시작 시각 기록
