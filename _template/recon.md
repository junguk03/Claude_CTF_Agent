# 정찰

모든 줄에 근거(`src/파일:줄` 또는 `out/` 파일)를 붙인다.

## 문서 요약
읽은 페이지(경로, 저장한 `out/` 파일)와 핵심 문장 인용. 설계 설명에 적힌 보안 동작은 그대로 옮긴다.
-

## 구성 요소와 경로
- 서버 종류 추정: (헤더·쿠키 이름·오류 페이지, 근거)
- 구성 요소: (프록시, 앱, DB, 봇, 내부 서비스)

| 경로 | 메서드 | 입력 위치 | 파라미터 | 인증 | 처리 위치 / 근거 |
|---|---|---|---|---|---|

## 인증 흐름
가입·로그인·세션 발급·권한 검사 순서.
-

## 쿠키·토큰

| 이름 | 발급 위치 | HttpOnly | SameSite | Secure | 형식 | 예측 가능성 | 근거 |
|---|---|---|---|---|---|---|---|

- JWT: 알고리즘 / 내용(사용자 ID, 권한, 만료) / 서명 검증 여부
- CSRF 토큰·OAuth state 검증 여부:

## 데이터 흐름
입력 → 저장 → 사용(렌더링, 쿼리, 명령, 내부 요청)
-

## 플래그 위치 추정
문제 설명, 이름(문제·레포·계정·경로), 문서 문구, 소스에서 플래그가 있을 곳과 닿는 데 필요한 것.
-

## 신뢰 경계

| 믿는 쪽 | 검사 없이 믿는 것 | 근거 |
|---|---|---|
