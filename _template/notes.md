# 노트

이 파일이 기준이다. 대화보다 이 파일을 믿는다. `/clear` 후 이 파일만 읽고 이어갈 수 있게 쓴다.

## 현재 상태
- 단계: 0 범위 확인
- 갈래: (A 소스 / B 블랙박스)
- 계정: (문제 인스턴스 안에서 만든 계정만. 대회 플랫폼 계정은 적지 않는다)
- 세션 얻는 법: (`solve.py`의 로그인 흐름)
- 확보한 능력:
- 실행 한도: (측정한 값: 요청 간격, 응답·업로드 크기, 실행 시간 제한, 봇 방문 주기 등)
- 바꾼 공유 자원: (끝나면 되돌릴 것)
- 카운터: attempt 0회 (10회마다 hypotheses.md 재검토) / 연속 기각 0 (3이면 정찰로)

## 확인된 사실
사실만 적는다. 각 줄에 근거(`src/파일:줄` 또는 `out/` 파일). 해석은 `hypotheses.md`로.
