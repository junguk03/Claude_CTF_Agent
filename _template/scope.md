# 범위 확인

대상에 요청하기 전에(브라우저 포함) 모두 채운다. 필수 칸이 비었거나 대상 주소가 문제 페이지와 다르면 대상에 요청하지 않고 받은 파일 분석과 로컬 재현만 한다 (CLAUDE.md 2번).
`solve.py`가 이 파일을 읽어 검사한다. 각 칸은 `- 이름: 값` 한 줄로 쓰고, 칸 이름은 바꾸지 않는다.

> 종류: "대회" 또는 "워게임".
> 공식 페이지 주소: 대회 필수. 워게임이면 "-".
> 문제 페이지 주소: 워게임 필수. 대회는 있으면 적는다.
> 문제 페이지 캡처 경로: 사람이 준 캡처 파일(예: src/challenge.png). 파일이 실제로 있어야 한다.
> 대상 주소 확인: 캡처에 적힌 주소와 "대상 주소"가 같으면 "일치".
> 수신 주소: XSS 봇 등 결과를 받을 곳. 없으면 "-".
