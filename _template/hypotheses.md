# 가설

- 근거(`src/파일:줄` 또는 `out/` 파일)가 있는 것만 표에 넣는다. 없으면 아래 "아이디어"에 둔다.
- 상태: 대기 / 시험중 / 확인 / 기각 / 보류. 확인·기각은 증거 칸에 `out/` 또는 `src/` 경로가 있어야 한다.
- 가능성: 상/중/하. 비용: 낮음/중간/높음. 거리: 성공하면 플래그까지 남은 단계 수(1 = 바로 플래그).
- 순위: 가능성 높고, 비용 낮고, 거리 짧은 순으로 위에 둔다.
- 칸 안에는 `|`를 쓰지 않는다. 상태를 바꾸면 `python3 check_hypotheses.py`를 실행한다.
